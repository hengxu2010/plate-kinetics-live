快速上手

Plate Kinetics Live 快速上手

Plate Kinetics Live 装在连着仪器的电脑上。它读取仪器软件自己写下的文件，自动记录每一次测量，边测边显示曲线，并把每个实验存成一个 .pk 实验文件和一个 Excel 表格。它从不控制仪器，也不改动仪器软件的任何文件。

有两个程序，用法相同：Plate Kinetics Live 用于装有 Omega 软件的 BMG LABTECH 读板仪；Plate Kinetics Live (Archimed) 用于 RocGene Archimed 实时荧光定量 PCR 仪。

  1. 安装。以管理员身份运行 PlateKineticsLive-Setup.exe（读板仪）或 PlateKineticsLive-Archimed-Setup.exe（PCR），按默认设置安装。装好后，后台服务立刻开始记录；以后开机自动启动，不需要有人登录，也不需要开着窗口。
  2. 照常测量。在 Omega 或 Archimed Analyzer 里开始实验。实验名取自 Omega 里填的 ID1（没填就用方案名），或 Archimed 的实验文件名。也可以事先在“设置 → 下一个实验”里给仪器定好名字和孔板布局。
  3. 看实时曲线。从开始菜单打开 Plate Kinetics Live。每台仪器一张卡片，显示第几轮和预计结束时间。测满 2 轮后，点“在分析里打开”看曲线；曲线随新数据自动更新。
  4. 标注样本。在分析页面里填样本名、分组和备注，调整阈值等分析设置。改动约 3 秒后自动存进这个实验，旁边显示“已保存 14:32”。按 Ctrl+S 立即保存，并更新 Excel 文件。
  5. 找到文件。点“打开数据文件夹”。每个实验在 Experiments\年-月\ 里有两个文件：.pk（完整的实验记录，双击就能打开）和同名的 .xlsx（“Full record”和“Basic data”两张表）。
  6. 留意通知。实验完成、提前停止、中断、很久没有新数据或没能保存时，屏幕右下角弹出 Windows 通知。窗口顶部的横幅说明出了什么问题、该怎么办。

记住三件事

  • 安装版关掉窗口不影响记录；便携版只在程序开着时记录。
  • 备份整个 PlateKineticsLive-data 文件夹（包括隐藏的 System），不要只备份 Experiments。
  • 误删了实验文件，可以在“实验”列表里恢复。

仅供科研使用，不用于临床诊断。完整说明见“用户手册”，安装和维护见“IT 指南”。

用户手册

1. 概览

Plate Kinetics Live 让仪器电脑上的每一次动力学测量都有完整、可靠的记录，并且可以边测边看曲线。

  • 自动记录。程序一直看着仪器软件写下的文件，记下每一轮读数。程序没在运行时结束的实验，下次启动时从仪器软件自己的文件里补全。
  • 实时曲线。测量中的实验可以直接在分析页面（Plate Kinetics Analysis）里看曲线、算动力学参数、做分组统计、出图和报告。分析页面也能导入其他仪器导出的数据文件。
  • 实验文件。每个实验自动得到一个 .pk 文件（完整记录）和一个 Excel 文件，按月份放在数据文件夹里。
  • 只读取。程序从不向仪器发送命令，也不写入、不锁住仪器软件的文件。
  • 不联网。程序不向任何地方发送数据。

2. 实时查看

每台仪器有一张卡片，显示：

  • 状态：空闲、测量中、已结束、提前结束或无法读取；
  • 实验名、方案、开始时间、操作者、第几轮（例如“第 12 / 300 轮”）、预计结束时间、温度和最新数据的时间；
  • 实验意外结束时的时间和原因，例如“提前结束：03:10 电脑因 Windows 更新重启”（见第 3 节）。

卡片上出现“已经 … 没有新数据了，请看一下仪器和 Omega 软件”时，是仪器软件很久没有写下新读数：请看一下仪器和仪器软件是否暂停、报错或在等人操作。

点“在分析里打开”，这次实验的曲线就在分析页面里打开，并随新数据自动更新；关掉“自动载入曲线”后不再自动更新。测满 2 轮后才能显示曲线；曲线只支持 96 孔和 384 孔板。拖动卡片上的圆点可以回看这次实验较早的时候，拖到最右边就回到实时。

结束超过 7 天的实验会从数据列表里收起；要看时在“实验”里打开。

操作者默认是实验开始时登录这台电脑的 Windows 用户。可以在“设置”里定一个默认操作者，也可以在每个实验的标注里修改。

3. 实验和实验文件

什么时候写文件

  • .pk：测量中每完成一轮写一次，实验结束时再写一次。实验结束后，原始数据就封存了：以后只可能补上漏掉的轮（从仪器软件的文件里读回），已有的数值永远不会再改。
  • .xlsx：实验结束时生成；保存标注以后按第 5 节的规则更新。

文件名

Experiments\2026-11\2026-11-20 14-05-32 Plate 7 - FLUOstar Omega 415-0123.pk
Experiments\2026-11\2026-11-20 14-05-32 Plate 7 - FLUOstar Omega 415-0123.xlsx

即开始时间、实验名、仪器型号和序列号，按开始的年月放在子文件夹里。实验名依次取自：“设置 → 下一个实验”里定的名字；Omega 里填的 ID1，没填就用方案名；Archimed 的实验文件名。Windows 不允许的字符会被去掉；和别的实验重名时，后面加“ (2)”“ (3)”。

.pk 实验文件

.pk 是一个实验的完整记录，双击就用 Plate Kinetics Live 打开。它是一个 zip 压缩包，里面有：

文件内容
README.txt一页中英文说明
info.json基本信息：实验编号（每个实验唯一，改名也不变）、实验名、仪器型号、序列号、仪器软件和版本、开始和结束时间（带时区，例如 2026-11-20T14:05:32+08:00）、状态、完成和计划的轮数、中断原因、操作者、原始数据的 SHA-256 校验值、封存时间
run.json原始数据：每一轮每个孔的读数、时间、温度、方案设置和事件
analysis.json保存的标注和分析结果（没保存过就没有这个文件）

请不要手工改动 .pk 里的文件。较新版本的 Plate Kinetics Live 做的 .pk 如果用的是新格式，旧版本会提示“由更新的 Plate Kinetics Live 制作，请更新程序”。

Excel 文件

和 .pk 同名的 .xlsx 有三张表：

  • Full record（完整记录）：实验的全部信息——实验名和编号、仪器、软件、方案、起止时间和时区、状态、中断原因、轮数、目标温度、每个通道的滤光片和增益、操作者、原始数据的校验值；样本（孔号、内容、保存的样本名和分组）；每个通道一张数据表（轮次、时间 (s)、温度 (°C)、每孔一列，孔号下面一行是样本名）；保存的分析结果；事件。
  • Basic data（基本数据）：只有数字——轮次、时间 (s)、温度 (°C)、每孔一列，每个通道一块。Excel、WPS、Prism 等都可以直接用。
  • Protocol（方案）：方案详情（见下），英文名称、中文名称、数值各占一列；读板仪的实验另有“Omega 原始值”：Omega 保存的每一项设置原样列出（不含 Omega 的用户账号）。

Excel 是副本，原始记录以 .pk 为准。Excel 文件丢了或被改乱了，在“实验”列表里点“重新生成 Excel”。

方案详情

程序为每个实验记下重复这个实验需要的设置，在分析页面的实验信息旁点“方案详情”展开查看，也写在 Excel 的“Protocol”表里：

  • 读板仪（Omega）：方案名称、板型、测量模式、方案最后保存时间、Omega 版本；循环次数 × 每轮时间、每孔闪光次数；每个通道的激发 / 发射滤光片和增益；振板设置；目标温度。取自实验开始时 Omega 的方案设置。
  • PCR（Archimed）：反应体积、热盖温度、运行模式、染料和检测项目；温度程序，每个阶段一行，例如“阶段 1 · 循环 99 次：80.0 °C 10:00 → 4.0 °C 5:00 (采光)”。取自实验文件（.qps / .qpt），找到后就存进程序的记录，之后实验文件再改也不影响；以前的实验在程序找到它的实验文件时补上。

Omega 存的是代码。已经和 Omega 的方案窗口核对过的，显示成文字（例如底读、稳定时间 0.1 秒、双轨道振板、900 rpm）；还没核对的（例如读板方向、速度，或者别的振板方式和频率）暂时显示为“Omega 代码 1”这样的数字，核对后会换成文字。旧版本记录的实验、或者找不到实验文件的 PCR 实验，显示“没有记录”。

“实验”列表

“实验”里列出数据文件夹中的所有实验。可以按名字、样本名、仪器、日期搜索，按仪器、日期和状态筛选。对每个实验可以：

  • 打开：在分析页面里打开，连同保存的标注；
  • 在文件夹中显示；
  • 改名：同时改 .pk 和 .xlsx 的文件名（实验编号不变）；
  • 重新生成 Excel；
  • 删除：把 .pk 和 .xlsx 移到回收站；
  • 恢复：删掉的实验单独列出，可以用程序自己保存的记录重新生成 .pk、.xlsx 和保存过的标注；
  • 导出当前数据：实验还在测量时，把到目前为止的数据导出成 Excel 文件。

也可以直接在资源管理器里改名，在 Experiments 里移动或删除文件：程序靠文件里的实验编号认文件，不靠文件名。已经结束的实验，文件被删后不会自动再生成；需要时在列表里恢复。

打开 .pk

双击 .pk 文件（安装版），或在“实验”里点“打开”。从别处拷来的 .pk（U 盘、邮件附件）也能打开；在这样的文件里做的标注保存进这个文件本身。

全部 BMG 实验（读板仪程序）

列出这台电脑上 Omega 数据库里的所有实验（Omega 的每个用户），包括装本程序之前做的。可以在分析页面里打开，也可以存成实验文件（.pk 和 .xlsx）。已验证 Omega 6.20 和 6.40 的板模式动力学、96 孔和 384 孔板；其他版本或模式的实验也会列出，但不保证能正确打开。

导出

在分析页面里导出表格、图片或报告时，“另存为”对话框直接打开这个实验所在的文件夹。导出的每个表、图和报告都注明数据来自哪个实验或文件，以及分析页面的版本。

备份

请备份整个 PlateKineticsLive-data 文件夹，包括隐藏的 System 文件夹：原始记录和恢复所需的一切都在 System 里，只备份 Experiments 不够。恢复时把整个文件夹放回程序旁边（安装版请 IT 先停止后台服务，见 IT 指南第 3 节）。

断电和坏文件

程序写文件时先写一个临时文件，确认写到磁盘上并读回核对后才替换原文件，同时留着上一版（.bak），所以断电不会留下写了一半的记录。启动时如果发现坏文件，程序把它挪到 System\recovery\日期-时间\（程序从不删除那里的文件），然后从 .bak 恢复；没有 .bak 就从仪器软件的文件重建。做了什么，窗口顶部的蓝色提示会说明。

磁盘空间

数据文件夹所在磁盘的剩余空间少于 5 GB 时出现警告，少于 1 GB 时出现错误。请尽快腾出空间，否则新数据可能无法保存。

5. 标注和自动保存

你在分析页面里给一个实验做的标注——样本名、分组、备注、操作者，以及分析设置（阈值、截断值等）——保存在这个实验里（.pk 里的 analysis.json），System 里另存一份用来恢复。原始读数永远不会被改动。

自动保存

  • 最后一次改动约 3 秒后自动保存，窗口里显示“已保存 14:32”。
  • 按 Ctrl+S（或点“保存”）立即保存。
  • 打开一个实验时，它保存的标注自动载入。读板仪的实验还没保存过标注时，样本名先用 Omega 里输入的样本信息（如果有）。

Excel 什么时候更新

自动保存只写 .pk，不会每次都重写 Excel。Excel 在这些时候更新：按 Ctrl+S 时；离开或关闭这个实验时；有改动时最多每 10 分钟一次。

如果 Excel 文件正开着，或者有人改过它，程序不会覆盖，而是在旁边另写一个 实验名 (analysis 2026-11-20 15-42).xlsx。Excel 出问题不会影响 .pk 的保存。

状态标签

分析旁边的状态标签说明你看到的标注是否已经存进了实验：

标签意思
与仪器端一致你看到的就是实验里保存的版本。
有改动只在这台设备上你的改动还没有存进实验，例如暂时连不上记录程序。程序每 30 秒重试一次。
仪器端有更新你还有没存进去的改动时，别人保存了一个更新的版本。

自己没有未保存的改动时，别人保存的新版本会自动载入。

恢复到仪器端

点“恢复到仪器端”：丢掉这台设备上还没存进实验的改动，载入实验里当前保存的版本。

退回上一版

点“退回上一版”：标注回到最后一次保存之前的样子（只能退一步）。这个按钮只在仪器电脑上的程序窗口里有。页面里的撤销（Ctrl+Z）撤销的是刚做的一步编辑；“退回上一版”撤销的是一次保存。

几个人标注同一个实验

每个实验只有一份共享的标注。几个人（例如这台电脑上的不同 Windows 用户）改同一个实验时，以最后一次保存为准；程序记下最后是谁（Windows 用户和电脑）、什么时候保存的。程序不保存修改历史。

数据文件夹以外的 .pk

从别处打开的 .pk（不在 Experiments 里），标注由窗口直接存进那个文件。

10. 更新

  • 安装版：以管理员身份运行新版本的安装程序。它装进原来的文件夹，数据文件夹保持不动。
  • 可以在测量中更新：安装程序会先说明“记录会停约 10 秒，不丢数据”，点“继续”才做。漏掉的读数从仪器软件的文件里补回，仪器软件不受影响。
  • 开着的窗口会被关掉，更新后从开始菜单重新打开；托盘自己换成新版本。
  • 更新失败时，原来的版本照常运行和记录。
  • 便携版：在没有实验测量时关掉程序，把新版本解压到原来的文件夹（覆盖程序文件，保留 PlateKineticsLive-data），再启动。
  • 当前版本号在“关于”里。那里还有“检查更新”：有新版本时窗口上方出现提示，点“立即更新”就下载安装程序、核对它的 SHA-256 后运行（需要管理员权限；有仪器在测量时先提醒“记录会停约 10 秒，不丢数据”）。便携版只给出下载页面，请按上一条手动更新。没有更新成功时，原来的版本照常运行，窗口会说明。
  • “自动检查更新”默认关闭，可以在“关于”里打开；“仅安装分析软件”和 Plate Kinetics Analysis 默认打开，可以关掉。不能访问 GitHub 的电脑不受影响。

11. 卸载

  • 在 Windows“设置 → 应用”里找到 Plate Kinetics Live，选“卸载”（需要管理员）。
  • 卸载会删掉程序、后台服务、托盘、快捷方式和 .pk 的文件关联。
  • 数据文件夹 PlateKineticsLive-data 留在原处，里面的实验和记录都还在。不再需要时自己删除（先备份）。
  • 便携版：关掉程序，删除它的文件夹（需要的话先把 PlateKineticsLive-data 拷出来）。

12. 常见问题

程序会控制仪器，或者改动仪器软件的文件吗？
不会。它只读取仪器软件写下的文件（与仪器软件共享读取），从不写入、锁住或改动它们，也从不向仪器发送命令。
数据会被发到网上吗？
不会。程序不收集使用统计，默认不主动连接任何地方；它的网页服务只对这台电脑本身开放。只有在“关于”里点“检查更新”（或者你打开了“自动检查更新”）时，程序才向 GitHub 查询最新版本号，不发送任何实验数据。数据只在你自己拷走或发出去时才会离开这台电脑。
关掉窗口还会记录吗？
安装版会：记录的是后台服务，窗口只用来看。便携版不会：关窗口就停止记录，关之前会提醒。
测量中停电或电脑重启了怎么办？
记录的写法是断电安全的。电脑重新开机后，安装版自动启动，从仪器软件的文件里补回漏掉的读数，实验标为“中断”并写明原因和时间。
可以改实验文件的名字、把它们挪到别的文件夹吗？
在 Experiments 里可以随意改名、移动、建子文件夹。挪出 Experiments 的文件，程序不再列出和管理，但双击仍可以打开，标注会存进那个文件。
误删了实验怎么办？
在“实验”列表里找到已删除的实验并恢复；也可以从回收站还原。
Excel 和 .pk 哪个算数？
.pk 是原始记录，Excel 是方便使用的副本。两者对不上时，在“实验”列表里重新生成 Excel。
怎么在别的电脑上看一个实验？
把 .pk 拷过去，用装了 Plate Kinetics Live（或便携版）的电脑打开；或者直接用 .xlsx。
几个人共用一台仪器电脑可以吗？
可以。后台服务不管谁登录都在记录；每个 Windows 用户有自己的窗口设置和托盘；每个实验的标注大家共用，以最后一次保存为准。
能在同一台电脑上装两个程序吗？
可以。读板仪程序用端口 47815，Archimed 程序用 47825，数据文件夹也各自分开。
同一个程序的便携版和安装版能同时运行吗？
不能，它们用同一个端口。安装程序发现便携版在运行时会停下来，请先关掉便携版。
时间是哪个时区的？
文件里的时间都带着电脑的时区，例如 2026-11-20T14:05:32+08:00，换到别的时区看也不会弄错。
可以用于临床诊断或受监管的记录吗？
不可以。本程序仅供科研使用，不是医疗器械软件，也不符合 21 CFR Part 11 等电子记录法规；它不保存修改历史，没有电子签名。需要合规记录时，以仪器软件自己的记录为准。

5. 端口和网络

  • BMG 程序用 TCP 端口 47815，Archimed 程序用 47825，只监听 127.0.0.1（本机回环地址）。其他电脑访问不到；不需要、也不会添加防火墙规则。
  • 每个请求都检查 Host 头（必须是 127.0.0.1:<端口> 或 localhost:<端口>），/api/ 请求还要带 System\api-token 里的令牌（本机用户可读）。这样网上的网页不能借浏览器读取或改动数据。
  • 程序默认不主动连接任何地方：没有使用统计，也不向仪器发送任何东西。唯一的外连是检查更新：用户在“关于”里点“检查更新”，或打开了“自动检查更新”（完整安装默认关闭）时，向 api.github.com 查询最新发布的版本；用户点“立即更新”时从 github.com（会转到 *.githubusercontent.com）下载安装程序，和发布页公布的 SHA-256 核对一致才运行。访问不了 GitHub 时什么都不受影响。WebView2 运行时是 Windows 的组件，由微软像 Edge 一样更新。
  • 端口被别的程序占用时，程序在日志和窗口里写出占用端口的进程。
  • 要从别的电脑查看，请用远程桌面。

6. 托盘

  • 注册表 HKLM\Software\Microsoft\Windows\CurrentVersion\Run 里有一个以程序名命名的值（例如 PlateKineticsLive）：每个用户登录时运行 "<exe>" --tray，每个用户会话只有一个。
  • 它每 10 秒读一次本机的状态，把新事件显示成 Windows 通知（按设置响铃）；服务 3 分钟没有回应时提醒一次。
  • 菜单：打开窗口、打开数据文件夹、退出。记录不需要托盘。
  • 已经报过的事记在 System\users\<用户>\tray.json（或 %LOCALAPPDATA%\<程序名>\tray.json）。
  • 个别用户不需要时，可以在任务管理器的“启动应用”里关掉。
  • 更新或搬家后，托盘自己换成新程序；卸载时结束。

7. 卸载

  • “设置 → 应用”，或者以管理员身份运行 "<程序文件夹>\PlateKineticsLive.exe" --uninstall；加 /S 静默（这时必须已经是管理员）。不是管理员时，它会请求提升一次权限。
  • 删除：服务、托盘和登录时的启动项、快捷方式、“应用”列表里的条目、.pk 文件类型、安装程序放进去的文件（包括更新时改名放在一边的 *.replaced-N）。
  • 保留：数据文件夹 PlateKineticsLive-data，以及不是安装程序放进去的文件。
  • 退出码：0 已卸载，1 失败，2 还有程序窗口开着（例如在另一个用户的会话里），3 取消，4 没有安装，5 服务删不掉。日志同样写进 %TEMP%\<程序名>-setup.log。

  • PlateKineticsLive-portable.zip 和 PlateKineticsLive-Archimed-portable.zip：解压到当前用户能写的文件夹（不要放在 Program Files 里，也不要直接在 zip 里运行），运行里面的 exe。

用 PlateKineticsLive-Setup.exe --move-to [<文件夹>]（不写文件夹就搬到 Program Files 里的标准位置），或在安装窗口里选别的文件夹。

  1. 新文件夹必须是新的或空的。磁盘空间不够、路径会超过 260 个字符，都事先拒绝，什么都不改。
  2. 程序文件写进新文件夹；数据文件夹（记录、日志、设置；不含网页缓存）在照常记录时先复制一遍，停下服务后再补上变了的。每个文件都和原件核对大小和 SHA-256。

Quick start

Plate Kinetics Live quick start

Plate Kinetics Live runs on the PC that drives the instrument. It reads the files the instrument software writes, records every measurement automatically, shows the curves while the plate is measured and keeps each experiment as one .pk experiment file and one Excel workbook. It never controls the instrument and never changes any file of the instrument software.

There are two programs that work the same way: Plate Kinetics Live for BMG LABTECH plate readers run by the Omega software, and Plate Kinetics Live (Archimed) for the RocGene Archimed real-time PCR instrument.

  1. Install. Run PlateKineticsLive-Setup.exe (plate readers) or PlateKineticsLive-Archimed-Setup.exe (PCR) as administrator and accept the defaults. Recording starts right away in a background service, which starts with Windows from then on: nobody needs to be signed in and no window needs to be open.
  2. Measure as usual. Start the run in Omega or Archimed Analyzer. The experiment is named after ID1 typed in Omega (else the protocol) or after the Archimed experiment file. You can also set a name and a plate layout in advance under Settings > Next experiment.
  3. Watch the curves. Open Plate Kinetics Live from the Start menu. Each instrument has a card with the cycle and the expected end. Once 2 cycles are done, click “Open in Analysis”: the curves update as new data arrive.
  4. Annotate. In the analysis page, enter sample names, groups and notes, and adjust settings such as the threshold. Changes are saved into the experiment about 3 seconds after you stop typing (“Saved 14:32”). Ctrl+S saves at once and also updates the Excel file.
  5. Find the files. Click “Open data folder”. Each experiment has two files in Experiments\year-month\: the .pk (the complete record; double-click to open it) and an .xlsx of the same name with the sheets “Full record” and “Basic data”.
  6. Watch for notifications. When a run completes, is stopped early, is interrupted, gets no new data for a long time or cannot be saved, a Windows notification appears at the bottom right. Banners at the top of the window say what is wrong and what to do.

Three things to remember

  • Installed edition: closing the window does not stop recording. The portable edition records only while it is open.
  • Back up the whole PlateKineticsLive-data folder, including the hidden System folder, not only Experiments.
  • Deleted an experiment file by mistake? Restore it from the Experiments list.

For research use only, not for diagnostic use. The user guide has the details; the IT guide covers installation and maintenance.

1. Overview

Plate Kinetics Live gives every kinetic measurement on the instrument PC a complete, reliable record, and lets you watch the curves while the plate is measured.

  • Automatic recording. The program follows the files the instrument software writes and records every cycle. A run that ended while the program was not running is completed from the instrument software's own files at the next start.
  • Live curves. A run in progress opens straight in the analysis page (Plate Kinetics Analysis): curves, kinetic parameters, group statistics, figures and reports. The analysis page also imports data files exported by other instruments.
  • Experiment files. Every run gets a .pk file (the complete record) and an Excel file, filed by month in the data folder.
  • Read only. The program never sends commands to an instrument and never writes or locks the instrument software's files.
  • Offline. The program sends no data anywhere.

2. Watching a run

Each instrument has a card that shows:

  • its state: Idle, Measuring, Finished, Ended early or Cannot be read;
  • the experiment name, protocol, start time, operator, cycle (for example “Cycle 12 / 300”), expected end, temperature and the time of the latest data;
  • when a run ended unexpectedly, the time and the reason, for example “Ended early: 03:10 the PC restarted for a Windows update” (see section 3).

“No new data for …: please check the instrument and the Omega software” means the instrument software has written no new reading for a long time: check whether the instrument or its software is paused, shows an error or waits for someone.

Click “Open in Analysis” to open the run's curves in the analysis page; they follow new data by themselves until you switch off “Load curves automatically”. Curves appear once 2 cycles are done, for 96- and 384-well plates. Drag the dot on the card to look back at an earlier moment of the run; at the right end it is live again.

Runs that ended more than 7 days ago are folded away in the data list; open them from Experiments.

The operator is the Windows user signed in at the PC when the run started. A default operator can be set in Settings, and each experiment's operator can be changed in its annotation.

3. Experiments and their files

When the files are written

  • .pk: after every completed cycle while the run measures, and once more at its end. From then on the raw data are sealed: only cycles that were missed can still be added (read back from the instrument software's files); values already recorded are never changed.
  • .xlsx: at the end of the run; after annotations are saved, as described in section 5.

File names

Experiments\2026-11\2026-11-20 14-05-32 Plate 7 - FLUOstar Omega 415-0123.pk
Experiments\2026-11\2026-11-20 14-05-32 Plate 7 - FLUOstar Omega 415-0123.xlsx

That is the start time, the experiment name, the instrument model and its serial number, in a folder for the month the run started. The experiment name is, in this order: the name set under Settings > Next experiment; ID1 typed in Omega, else the protocol; the Archimed experiment file's name. Characters Windows does not allow are left out; a name another experiment has already gets “ (2)”, “ (3)”.

The .pk experiment file

A .pk is the complete record of one experiment; double-click it to open it in Plate Kinetics Live. It is a zip file holding:

FileContent
README.txtOne page about the file, in Chinese and English

The Excel file

The .xlsx beside the .pk has three sheets:

  • Full record: everything about the run: experiment name and id, instrument, software, protocol, start and end with the time zone, status, why it was interrupted, cycles, target temperature, filters and gain per channel, operator, the checksum of the raw data; the samples (well, content, saved names and groups); per channel a table (Cycle, Time (s), Temperature (°C), one column per well, with the sample names in the row under the well ids); the saved analysis results; the events.
  • Basic data: only the numbers: Cycle, Time (s), Temperature (°C), one column per well, one block per channel; ready for Excel, WPS, Prism and the like.
  • Protocol: the protocol details (see below), with the English name, the Chinese name and the value in columns of their own; for a plate-reader run also “Omega original values”: every setting Omega stored, as it stored it (without Omega’s user accounts).

The workbook is a copy; the .pk is the original record. If the workbook is lost or was changed, use “Regenerate Excel” in the Experiments list.

Protocol details

For every experiment the program records the settings needed to repeat it. Click “Protocol details” next to the experiment’s information in the analysis page to see them; they are also in the Excel sheet “Protocol”:

  • Plate reader (Omega): protocol name, plate, mode, when the protocol was last saved, Omega version; cycles × cycle time, flashes per well; excitation / emission filters and gain of each channel; shaking; target temperature. Taken from Omega’s protocol settings at the start of the run.
  • PCR (Archimed): sample volume, cover temperature, run mode, dyes and detectors; the temperature program, one line per stage, e.g. “Stage 1 · Cycling × 99: 80.0 °C 10:00 → 4.0 °C 5:00 (data collected)”. Taken from the experiment file (.qps / .qpt) and stored in the program’s record once found, so a later change of the file does not alter it; earlier runs get it when the program finds their experiment file.

Omega stores codes. Those checked against Omega's protocol window are shown in words (for example Bottom optic, settling time 0.1 s, Double orbital shaking, 900 rpm); the others (for example the reading direction, the speed, or other shaking modes and frequencies) are shown as numbers such as “Omega code 1” until they are checked. Runs recorded by an earlier version, and PCR runs whose experiment file is not found, show “No record”.

5. Annotations and automatic saving

What you add to an experiment in the analysis page (sample names, groups, notes, the operator and the analysis settings such as threshold or cut-off) is saved in the experiment itself (analysis.json in the .pk), with a copy in System for restoring. The raw readings are never changed.

Automatic saving

  • About 3 seconds after your last change it is saved; the window shows “Saved 14:32”.
  • Ctrl+S (or Save) saves at once.
  • When an experiment is opened, its saved annotation is applied. For a plate reader run with nothing saved yet, the sample information entered in Omega (where there is any) gives the first sample names.

When the Excel file is updated

Automatic saving writes the .pk only, not the workbook every time. The workbook is updated when you press Ctrl+S, when you leave or close the experiment, and at most every 10 minutes while there are changes.

If the workbook is open in Excel or someone changed it, the program never overwrites it: it writes name (analysis 2026-11-20 15-42).xlsx beside it instead. A problem with the workbook never stops the .pk from being saved.

12. FAQ

Does the program control the instrument or change the instrument software's files?
No. It only reads the files the instrument software writes (sharing them for reading), never writes, locks or changes them, and never sends commands to an instrument.
Is any data sent over the internet?
No. The program collects no usage statistics and connects nowhere by default; its web server is open to this PC only. Only when you click “Check for updates” under About (or have turned on the automatic check) does it ask GitHub for the latest version number; no experiment data are sent. Data leave the PC only when you copy or send them yourself.
Does it still record when I close the window?
Installed edition: yes, the service records and the window only shows. Portable edition: no, closing the window stops recording (you are asked first).
What if the power fails or the PC restarts during a run?
Records are written power-safely. When the PC is back, the installed edition starts by itself, reads the missed readings back from the instrument software's files, and marks the run as interrupted with the time and the reason.
May I rename experiment files or move them to other folders?
Within Experiments, rename, move and make subfolders as you like. A file moved out of Experiments is no longer listed or managed, but a double-click still opens it and annotations are saved into it.
I deleted an experiment by mistake.
Find it among the deleted experiments in the Experiments list and restore it, or take it back from the Recycle Bin.
Which counts, the Excel file or the .pk?
The .pk is the original record; the workbook is a copy for convenience. If they differ, regenerate the workbook from the Experiments list.
How do I look at an experiment on another PC?
Copy the .pk and open it on a PC with Plate Kinetics Live (installed or portable), or use the .xlsx.
Can several people share one instrument PC?
Yes. The service records whoever is signed in; each Windows user has their own window settings and tray; the annotation of each experiment is shared, and the last save wins.
Can both programs be installed on one PC?
Yes. The plate reader program uses port 47815, the Archimed program 47825, and each has its own data folder.
Can the portable and the installed edition of the same program run together?
No, they use the same port. The installer stops when it finds the portable edition running: close it first.
Which time zone are the times in?
Every time in the files carries the PC's UTC offset, for example 2026-11-20T14:05:32+08:00, so they read correctly anywhere.
May it be used for diagnosis or regulated records?
No. The program is for research use only. It is not medical device software and not an electronic records system under 21 CFR Part 11 or similar rules: it keeps no change history and has no electronic signatures. Where records must comply, the instrument software's own records are the reference.

5. Ports and network

  • The BMG program uses TCP port 47815, the Archimed program 47825, listening on 127.0.0.1 (loopback) only. Other PCs cannot reach it; no firewall rule is needed or added.
  • Every request must carry the Host 127.0.0.1:<port> or localhost:<port>, and /api/ requests also the token from System\api-token (readable by local users). Web pages from the internet therefore cannot read or change anything through a browser.
  • By default the program opens no outgoing connections: no usage statistics, nothing sent to the instruments. The one exception is the update check: when a user clicks “Check for updates” under About, or has turned on the automatic check (off by default for a full installation), it asks api.github.com for the latest release; “Update now” downloads the installer from github.com (redirected to *.githubusercontent.com) and runs it only when its SHA-256 equals the one published with the release. Nothing depends on GitHub being reachable. The WebView2 Runtime is a Windows component that Microsoft updates like Edge.
  • When the port is held by another program, the log and the window name the process that holds it.
  • To look from another PC, use Remote Desktop.

6. The tray

  • A value named after the program (for example PlateKineticsLive) under HKLM\Software\Microsoft\Windows\CurrentVersion\Run runs "<exe>" --tray at every sign-in; one per user session.
  • It reads the local state every 10 seconds and shows each new event as a Windows notification (with a sound if set); once when the service has not answered for 3 minutes.
  • Menu: Open window, Open data folder, Quit. Recording does not need the tray.
  • What it has shown is kept in System\users\<user>\tray.json (or %LOCALAPPDATA%\<name>\tray.json).
  • A user who does not want it can switch it off under Startup apps in Task Manager.
  • After an update or a move it changes to the new program by itself; an uninstall ends it.

7. Uninstalling

  • Settings > Apps, or as administrator "<program folder>\PlateKineticsLive.exe" --uninstall; /S makes it silent (then it must run as administrator already). Without administrator rights it asks for them once.
  • Removed: the service, the tray and its sign-in entry, the shortcuts, the entry in the list of apps, the .pk file type, the files the installer put in place (including the *.replaced-N copies an update renamed aside).
  • Kept: the data folder PlateKineticsLive-data and every file the installer did not put there.
  • Exit codes: 0 removed, 1 failed, 2 a program window is still open (for example in another user's session), 3 cancelled, 4 not installed, 5 the service could not be removed. The log is %TEMP%\<name>-setup.log as well.

8. Offline package

PlateKineticsLive-offline.zip is for PCs without internet access. It holds both installers, a README.txt and, in the redist folder, Microsoft's own installers unchanged: ndp48-x86-x64-allos-enu.exe (.NET Framework 4.8) and MicrosoftEdgeWebView2RuntimeInstallerX64.exe (WebView2 Runtime).

9. Portable edition

  • PlateKineticsLive-portable.zip and PlateKineticsLive-Archimed-portable.zip: unzip into a folder the user can write to (not under Program Files, and do not run it from inside the zip), then run the exe.
  • One process does everything: it records only while it is open and asks before its window closes. No service, no tray, no file association, no permissions set.
  • The data folder is beside the exe, laid out as in the installed edition.
  • Open a .pk with “Open with” and the exe; when the program is running already, the file is handed to it.

10. Moving to another folder

Use PlateKineticsLive-Setup.exe --move-to [<folder>] (no folder: the standard one under Program Files), or choose another folder in the installer's window.

  1. The new folder must be new or empty. Too little disk space, or paths longer than 260 characters, are refused up front and nothing is changed.
  2. The program files are written into the new folder; the data folder (records, logs, settings; not the web caches) is copied once while recording goes on, then, with the service stopped, what changed meanwhile. Every copied file is checked against the original (size and SHA-256).
  3. The new service is first registered to start on demand; once it answers with every instrument the old one showed, it is set to start with Windows and the old service is removed; shortcuts, the apps entry, the .pk association and the tray follow the new folder.
  4. Any failure puts everything back (exit code 9): the new service and folder go, the old service runs again from the old folder.
  5. The old folder is never changed: it stays as a backup that you delete once all is well. Recording pauses about 10–20 seconds; nothing is lost.
