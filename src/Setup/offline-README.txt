Plate Kinetics Live - 离线安装包 / offline package
==================================================

这个文件夹给不能上网的电脑用。
1. 把整个文件夹复制到仪器电脑上（不要只复制安装程序）。
2. 以管理员身份运行安装程序 PlateKineticsLive-Setup.exe（BMG Omega 读板仪）。
3. 电脑缺少 .NET Framework 4.8 或 WebView2 运行时的话，安装程序会先从 redist 文件夹里把它装上
   （只用带微软有效签名的文件；需要几分钟，请不要在仪器测量时安装）。
redist 文件夹里是微软自己的安装程序，原样放在这里。

This folder is for PCs without internet access.
1. Copy the whole folder to the instrument PC (not only the installer).
2. Run the installer PlateKineticsLive-Setup.exe (BMG Omega plate readers) as administrator.
3. Should the PC lack the .NET Framework 4.8 or the WebView2 Runtime, the installer installs it from the redist
   folder first (only files with Microsoft's valid signature; it takes a few minutes; not while an instrument
   measures).
The redist folder holds Microsoft's own installers, unchanged.
